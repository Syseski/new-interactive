# Panduan Gambar Permainan Teka Silang Kata (Aktiviti 8)

Anda boleh meletakkan fail gambar (.png / .jpg / .webp) di dalam folder ini:
`public/images/crossword/`

### Set 1: Haiwan
- `kucing.png` (atau `1.png`)
- `kuda.png` (atau `2.png`)
- `ikan.png` (atau `3.png`)
- `ayam.png` (atau `4.png`)

### Set 2: Buah-buahan
- `betik.png` (atau `set2_1.png` / `5.png`)
- `epal.png` (atau `set2_2.png` / `6.png`)
- `kelapa.png` (atau `set2_3.png` / `7.png`)
- `anggur.png` (atau `set2_4.png` / `8.png`)

Permainan akan memaparkan fail gambar yang anda masukkan secara automatik.
Sekiranya fail gambar belum dimasukkan atau gagal dimuat, permainan akan memaparkan ilustrasi vektor comel sebagai sandaran (*fallback*).

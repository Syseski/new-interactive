# Panduan Gambar Permainan Pilih Jawapan Betul

Anda boleh meletakkan fail gambar (.png / .jpg / .webp) di dalam folder ini:
`public/images/choose-correct/`

### Nama Fail untuk 4 Soalan:
- `1.png` (Gambar Gitar)
- `2.png` (Gambar Tuala)
- `3.png` (Gambar Rusa)
- `4.png` (Gambar Daun)

### Gambar Latar Belakang (*Background*):
- `bg.png` (atau `background.png` / `bg.jpg`)

Sekiranya fail gambar belum dimasukkan, permainan akan memaparkan lukisan latar belakang pemandangan alam semula jadi dan ilustrasi comel sebagai sandaran (*fallback*) secara automatik.

# Panduan Gambar Permainan Isi Tempat Kosong

Anda boleh meletakkan fail gambar (.png / .jpg / .webp) di dalam folder ini:
`public/images/fill-in/`

### Senarai Fail Mengikut Set:
- **Set 1 (Cikgu Anis)**: `scene.png` (atau `1.png`)
- **Set 2 (Irfan & Ayah Mencuci Motor)**: `scene2.png` (atau `2.png`)

Permainan akan memaparkan fail gambar ini mengikut set yang dipilih.
Sekiranya fail gambar belum dimasukkan atau gagal dimuat, permainan akan memaparkan ilustrasi vektor sebagai sandaran (*fallback*).

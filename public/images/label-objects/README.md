# Panduan Gambar Permainan Label Objek (Aktiviti 7)

Anda boleh meletakkan fail gambar (.png / .jpg / .webp) di dalam folder ini:
`public/images/label-objects/`

### Senarai Fail Mengikut Set:
- **Set 1 (Bilik Darjah)**: `scene.png` (atau `1.png`)
  - Bintang 1-6: Langsir, Papan Hitam, Jam, Tingkap, Kerusi, Pintu
- **Set 2 (Stesen Bas)**: `scene2.png` (atau `2.png`)
  - Bintang 1-6: Kereta, Buku, Bas, Beg, Pokok, Motor

Permainan akan memaparkan fail gambar mengikut set yang dipilih secara automatik.
Sekiranya fail gambar belum dimasukkan atau gagal dimuat, permainan akan memaparkan ilustrasi vektor sebagai sandaran (*fallback*).

# Panduan Gambar Permainan Seret & Padan (5 Box Bergambar)

Anda boleh meletakkan fail gambar (.png / .jpg / .webp) di dalam folder ini (`public/images/match/`).

### Nama Fail untuk Set 1:
- `1.png` (Gambar Kucing / Box 1)
- `2.png` (Gambar Kereta / Box 2)
- `3.png` (Gambar Kasut / Box 3)
- `4.png` (Gambar Kerusi / Box 4)
- `5.png` (Gambar Burung / Box 5)

Permainan akan memuatkan gambar fail anda secara automatik. Sekiranya fail gambar belum dimasukkan, permainan akan memaparkan lukisan vektor ilustrasi comel sebagai sandaran (fallback).
